# ⚙️ Chatty Backend

Chatty Backend powers the Chatty mobile application by handling user authentication, messaging, media management, and real-time communication services.

## ✨ Features

* User authentication
* Real-time messaging support
* Message management
* Media upload handling
* User profile management
* MySQL database integration

## 🛠️ Built With

* Java EE
* MySQL
* Apache Tomcat
* WebSocket

## 🚀 Getting Started

Import the project into NetBeans or your preferred Java IDE, configure the MySQL database, and deploy to Apache Tomcat.

## 📡 API Services

* Authentication
* User Management
* Messaging
* Media Handling
* Real-Time Communication
